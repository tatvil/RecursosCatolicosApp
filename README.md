# Recursos Católicos

Aplicación Android para acceder a recursos católicos diarios, incluyendo:

- **Santo del día**
- **Lecturas de la Biblia**
- **Rosario**
- **Evangelio del día**
- **Oraciones diarias**

---

## Características

- Mostrar el **santo del día** automáticamente según la fecha.
- Acceso rápido a **lecturas bíblicas**.
- Guía para rezar el **Rosario**.
